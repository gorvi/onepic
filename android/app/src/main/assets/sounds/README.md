# 音效文件说明

## 音效文件位置

将音效文件放在 `app/src/main/assets/sounds/` 目录下。

**注意**：音效文件需要手动下载并放入此目录，应用会从 assets 加载这些文件。

## 需要的音效文件

1. **snap.mp3** - 拼图块合并/吸附音效
   - 建议：短促的"咔哒"声或"点击"声
   - 时长：0.1-0.3秒

2. **swap.mp3** - 拼图块交换音效
   - 建议：滑动或交换的声音
   - 时长：0.2-0.4秒

3. **complete.mp3** - 拼图完成音效
   - 建议：胜利、成功或庆祝的音效
   - 时长：1-2秒

4. **revert.mp3** - 拼图块回退音效
   - 建议：轻微的"回弹"或"取消"声
   - 时长：0.1-0.2秒

5. **push.mp3** - 拼图块推挤音效
   - 建议：轻微的"推动"声
   - 时长：0.2-0.3秒

## 音效格式要求
- **格式**：MP3 或 OGG（推荐 OGG，文件更小）
- **采样率**：22050 Hz 或 44100 Hz
- **比特率**：64-128 kbps（足够清晰且文件小）
- **声道**：单声道（Mono）即可，文件更小

## 免费音效资源网站推荐

1. **Freesound** (https://freesound.org/)
   - 免费音效库，需要注册
   - 搜索关键词：click, snap, success, puzzle, game

2. **Zapsplat** (https://www.zapsplat.com/)
   - 免费音效库，需要注册
   - 有游戏音效分类

3. **OpenGameArt** (https://opengameart.org/)
   - 免费游戏资源，包括音效
   - 搜索关键词：sound effect, sfx

4. **Mixkit** (https://mixkit.co/free-sound-effects/)
   - 免费音效，无需注册
   - 可直接下载

## 注意事项

- 如果音效文件不存在，游戏会正常运行，只是没有音效
- 音效文件会自动从 assets 加载到缓存目录
- 建议音效文件总大小控制在 500KB 以内，避免应用体积过大

## 测试

添加音效文件后，重新编译运行应用，在以下操作时应该能听到音效：
- 拼图块合并时 → snap.mp3
- 拼图块交换时 → swap.mp3
- 拼图块推挤时 → push.mp3
- 拼图块回退时 → revert.mp3
- 拼图完成时 → complete.mp3
