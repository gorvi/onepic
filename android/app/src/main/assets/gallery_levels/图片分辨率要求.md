# 竖屏手机拼图图片分辨率要求

## 📱 核心要求

### 1. **最佳分辨率（推荐）**
- **尺寸**：`1024 x 1536` 像素（3:4 比例）
- **格式**：PNG（推荐）或 JPG
- **文件大小**：每张 500KB - 2MB
- **说明**：这个尺寸会被系统自动缩放到 1024 像素（最大边），正好匹配代码中的限制

### 2. **最小分辨率（可接受）**
- **尺寸**：`800 x 1200` 像素（3:4 比例）
- **说明**：低于此分辨率可能导致拼图块不够清晰

### 3. **最大分辨率（不推荐超过）**
- **尺寸**：`2048 x 3072` 像素（3:4 比例）
- **说明**：超过此尺寸会被大幅压缩，浪费存储空间

## 🎯 为什么选择 3:4 比例？

1. **竖屏适配**：手机屏幕是竖屏的，3:4 比例最符合屏幕形状
2. **拼图体验**：竖屏图片在竖屏手机上显示更自然
3. **网格匹配**：游戏网格是矩形（如 6x8），竖屏图片更合适

## 📐 分辨率计算说明

### 代码中的处理逻辑：
1. **加载阶段**：图片会被缩放到最大边 1024 像素
   ```kotlin
   val maxDim = 1024  // 代码中的限制
   ```

2. **切分阶段**：图片按网格切分
   - 例如：6x8 网格 = 48 块
   - 每块尺寸 = 1024/8 × 1536/6 = 128 × 256 像素

3. **显示阶段**：拼图块会根据屏幕尺寸自适应缩放
   - 屏幕宽度：1080 或 1440 像素（常见手机）
   - 游戏区域：约 1000-1300 像素宽（减去边距和顶部栏）
   - 每块最终显示：约 120-160 像素宽

## ✅ 图片质量要求

### 必须满足：
- ✅ **清晰度**：图片清晰，无模糊
- ✅ **对比度**：明暗对比明显，便于识别拼图块
- ✅ **细节丰富**：有足够的细节，避免纯色或过于简单
- ✅ **色彩饱和**：色彩丰富，视觉效果好

### 避免：
- ❌ 过于模糊的图片
- ❌ 纯色或渐变简单的图片
- ❌ 文字过多的图片（切分后可能看不清）
- ❌ 过于复杂的图片（可能影响识别）

## 🎨 图片风格建议

### 推荐风格：
1. **自然风景**：山川、湖泊、森林（细节丰富）
2. **建筑地标**：著名建筑、城市景观（线条清晰）
3. **动物**：野生动物、宠物（特征明显）
4. **艺术插画**：手绘风格、数字艺术（色彩丰富）
5. **美食**：精美食物、料理（视觉吸引力强）

### 不推荐：
- 纯文字图片
- 过于抽象的艺术
- 低对比度的图片
- 过于暗或过于亮的图片

## 🔧 图片处理建议

### 批量处理工具：
1. **Photoshop**：批量调整尺寸
2. **GIMP**：免费开源工具
3. **ImageMagick**：命令行批量处理
4. **在线工具**：如 TinyPNG（压缩优化）

### 批量调整脚本示例（ImageMagick）：
```bash
# 调整所有图片到 1024x1536，保持比例，填充背景
for file in *.jpg; do
    convert "$file" -resize 1024x1536^ -gravity center -extent 1024x1536 "resized_$file"
done
```

## 📝 总结

**推荐配置**：
- **分辨率**：1024 × 1536 像素
- **比例**：3:4（竖屏）
- **格式**：PNG（无损）或高质量 JPG
- **文件大小**：每张 500KB - 2MB
- **数量**：50 张

这样配置可以确保：
- ✅ 在所有手机上清晰显示
- ✅ 拼图块有足够的细节
- ✅ 文件大小适中
- ✅ 加载速度快
