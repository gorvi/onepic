Gallery Levels 图片目录
=====================

请将50张图片放在此目录下。

命名建议：
---------
方案1（推荐）：按数字顺序
  01.png, 02.png, 03.png, ..., 50.png

方案2：按风格分类
  01_nature.png, 02_architecture.png, 03_animals.png, ...

方案3：混合命名
  01_风格1.png, 02_风格2.png, ...

注意事项：
---------
- 支持的格式：.png, .jpg, .jpeg
- 建议分辨率：至少 800x800 像素
- 建议文件大小：每张不超过 2MB
- 图片会按文件名排序后分配

分配规则：
---------
- 关卡 1-10：  3x3 网格（简单）
- 关卡 11-20： 3x4 网格（简单+）
- 关卡 21-30： 4x5 网格（中等）
- 关卡 31-40： 5x6 网格（困难）
- 关卡 41-50： 6x8 网格（专家）

如果图片少于50张，系统会智能循环使用。
