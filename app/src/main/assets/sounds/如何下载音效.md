# 如何下载音效文件

## 方法一：使用浏览器下载（推荐）

1. 访问免费音效网站（推荐）：
   - **Mixkit**: https://mixkit.co/free-sound-effects/
   - **Freesound**: https://freesound.org/
   - **Zapsplat**: https://www.zapsplat.com/

2. 搜索并下载以下类型的音效：
   - **snap.mp3** - 点击/轻触音效（用于拼图块合并）
   - **swap.mp3** - 滑动/交换音效（用于拼图块交换）
   - **complete.mp3** - 成功/完成音效（用于拼图完成）
   - **revert.mp3** - 回退/取消音效（用于拼图块回退）
   - **push.mp3** - 推动音效（用于拼图块推挤）

3. 将下载的文件重命名为对应的文件名，放入 `app/src/main/assets/sounds/` 目录

## 方法二：使用命令行下载（需要网络）

在项目根目录执行以下命令（需要安装 curl 或使用 PowerShell）：

```bash
# 进入音效目录
cd app/src/main/assets/sounds

# 下载音效文件（示例 URL，可能需要替换）
curl -L -o snap.mp3 "音效文件URL"
curl -L -o swap.mp3 "音效文件URL"
curl -L -o complete.mp3 "音效文件URL"
curl -L -o revert.mp3 "音效文件URL"
curl -L -o push.mp3 "音效文件URL"
```

## 音效要求

- **格式**：MP3 或 OGG（推荐 MP3）
- **采样率**：22050 Hz 或 44100 Hz
- **比特率**：64-128 kbps
- **声道**：单声道（Mono）即可
- **时长**：
  - snap/swap/revert/push: 0.1-0.3秒
  - complete: 1-2秒
- **文件大小**：建议每个文件 < 100KB

## 测试

添加音效文件后，重新编译运行应用，在以下操作时应该能听到音效：
- 拼图块合并时 → snap.mp3
- 拼图块交换时 → swap.mp3
- 拼图块推挤时 → push.mp3
- 拼图块回退时 → revert.mp3
- 拼图完成时 → complete.mp3

## 注意事项

- 如果音效文件不存在，游戏会正常运行，只是没有音效
- 确保文件名完全匹配（区分大小写）
- 建议使用短小精悍的音效，避免应用体积过大
